  - Description: First Incoming → qualified Replace → Build linked extension locally → Reload. Yes now stages a reference and **does not ask for a dimension or move the source**. Fill title/materials and inspect Preview: the planned filenames use Core's prospective artifact lineage and suffix sequence 01/02, but original files still exist. Change Title or Parent if desired; only the currently qualified draft may allocate names. Cancel final Create once and verify no changes. Repeat, review and confirm a single Core transaction: new `.trace.md`, moved PNGs, local Markdown links, per-material descriptions, no previous source file, no lock/journal debt. Remove a pending reference before Create and verify it does not move. Test fail-closed source drift or unsafe target when safe to do so.

  - Transfer Kind: work
  - Description: Confirm Tiinex Explorer Move/Rebase action is still present and Core-owned Move/Prepend/Normalize Preview/Apply still works on disposable qualified artifacts. Reopen saved Evidence and confirm valid descriptions, links, and self integrity; inspect README cropped PNGs instead of animated GIFs. End with normal Handoff → Outgoing → Pack and the canonical Handoff Pointer preview. A short silent video or first exact failing error suffices; disposable test packages need not be returned.
  - Controlling Artifact: [Sigma Automatic Lineage And Atomic Attachment Create Windows Acceptance](001-40-3-3-3-sigma-automatic-lineage-and-atomic-attachment-create-windows-acc.trace.md)
