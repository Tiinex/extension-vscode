## Exclusions And Dependencies

- stale-is-warning-only
  - Kind: excluded-scope
  - Description: a resolvable permalink whose master candidate has different bytes is stale/degraded only and must not be promoted to an error merely because newer bytes exist.
  - Responsible Party Or Role: Core Tooling / VS Code host

- master-is-not-authority
  - Kind: excluded-scope
  - Description: `master` is used only to discover a possible latest repository/path candidate; it does not replace the artifact's declared version-bearing authority and no upgrade occurs without explicit operator Quick Fix selection.
  - Responsible Party Or Role: Core Tooling / VS Code host

- no-silent-network-inference
  - Kind: excluded-scope
  - Description: host/network inability to verify a permalink remains warning-level unavailable evidence and must not be fabricated into a proven missing reference.
  - Responsible Party Or Role: VS Code host / Core Tooling

- no-grounding-lane-redefinition
  - Kind: excluded-scope
  - Description: this VS Code branch must not replace, reinterpret or delay the main return-recipient grounding acceptance lane.
  - Responsible Party Or Role: Anchor
