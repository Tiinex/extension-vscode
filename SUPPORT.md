# Tiinex VS Code support

For reproducible extension problems, use the [Tiinex VS Code issue tracker](https://github.com/Tiinex/extension-vscode/issues).

Please include:

- VS Code version and operating system.
- Tiinex extension version.
- The operation you were performing (`Incoming`, `Outgoing`, `Pack`, `Transport`, Git, or authoring).
- The visible Tiinex finding/error text, if any.
- A short reproduction sequence.

Do **not** attach private Handoff packages or Workspace source unless you have explicitly reviewed them for disclosure. A screenshot or silent screen recording of the operator flow is often enough to establish the UI/state boundary first.

For security-sensitive reports, avoid posting secrets, credentials, private package contents, or repository material in a public issue. Use the security reporting path configured for the Tiinex organization/repository when one is available.
